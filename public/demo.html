// 30-SECOND INTEGRATION

Drop into your stack with zero fuss

Zero build steps, zero client libraries. Embed via Next.js App Router, Express, Vercel, Netlify, or raw HTML.

▲ Next.js 14+ (App Router `not-found.tsx`)

Embed directly in your root app/not-found.tsx.

export default function NotFound() { return ( <iframe src="https://witty-404.zimkk.workers.dev/html?theme=dark" style={{ width: '100vw', height: '100vh', border: 'none', display: 'block' }} title="404 Page" /> ); }
⚡ Express / Fastify Middleware

Catch unhandled routes and stream the live HTML.

app.use((req, res) => { fetch('https://witty-404.zimkk.workers.dev/html') .then(r => r.text()) .then(html => res.status(404).type('html').send(html)); });
🌐 Vercel (`vercel.json`)

Proxy unhandled routes at edge with path roasting.

{ "routes": [ { "handle": "filesystem" }, { "src": "/(.*)", "dest": "https://witty-404.zimkk.workers.dev/roast?path=/$1&format=html", "status": 404 } ] }
🖼️ Pure HTML Embed

Zero build tools, perfect full-bleed error page.
