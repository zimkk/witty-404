Four Ways to Consume the Engine

Whether you need a full standalone web page, structured JSON for custom UI, or raw text logs for the terminal, witty-404 provides dedicated endpoints.

GET /html HTML

Full-Bleed Web Page

Complete error page featuring animated diagnostics, synchronized flight trajectory crash, and action toolbar.

<iframe src="https://witty-404.zimkk.workers.dev/html"></iframe>
GET /json JSON

Structured REST Payload

Raw JSON response with disaster headline, subtitle, diagnostic logs array, footnote, and category tags.

curl -s https://witty-404.zimkk.workers.dev/json
GET /terminal LOGS

CLI & Terminal Logs

Returns step-by-step diagnostic log strings for terminal output, build scripts, and CLI tools.

curl -s https://witty-404.zimkk.workers.dev/terminal
GET /roast DYNAMIC

Path-Aware Roaster

Injects the exact missing client route into the disaster scene with strict HTML sanitization.

/roast?path=/api/v2/user/delete&format=html

Zero-Configuration Framework Recipes

Drop witty-404 into your existing stack in under 30 seconds with zero build dependencies.

Next.js 14+ (App Router not-found.tsx)
export default function NotFound() { return ( <iframe src="https://witty-404.zimkk.workers.dev/html?theme=dark" style={{ width: "100vw", height: "100vh", border: "none", display: "block" }} title="404 Error Page" /> ); }
Express.js / Fastify Middleware
app.use((req, res) => { fetch('https://witty-404.zimkk.workers.dev/html') .then(r => r.text()) .then(html => res.status(404).type('html').send(html)); });
Vercel (vercel.json)
{ "routes": [ { "handle": "filesystem" }, { "src": "/(.*)", "dest": "https://witty-404.zimkk.workers.dev/roast?path=/$1&format=html", "status": 404 } ] }
Pure HTML Embed
<iframe src="https://witty-404.zimkk.workers.dev/html?theme=dark" style="width: 100vw; height: 100vh; border: none; display: block;" title="404 Error Page" ></iframe>
