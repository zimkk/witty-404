Use this as your site's 404 page

Drop `/html` into your web project in 30 seconds via iframe or standard CDN rewrites.

🖼️ Option 1: Standalone HTML / iframe

Fill your custom 404 container completely with no external dependencies or CSS leakage.

<iframe src="https://witty-404.hassannazir.dev/html?theme=dark" style="width: 100vw; height: 100vh; border: none; display: block;" title="404 Page" ></iframe>
▲ Option 2: Vercel (vercel.json)

Proxy any unhandled route directly to witty-404's roast engine.

{ "routes": [ { "handle": "filesystem" }, { "src": "/(.*)", "dest": "https://witty-404.hassannazir.dev/roast?path=/$1&format=html", "status": 404 } ] }
🌐 Option 3: Netlify (_redirects)

Add a single line in your public/_redirects file.

/* https://witty-404.hassannazir.dev/html 404!
// HTTP ENDPOINTS

Clean, unauthenticated, CORS-open API

All endpoints support Access-Control-Allow-Origin: * and respond in sub-millisecond edge latency.

METHOD & PATH RETURNS DESCRIPTION & PARAMETERS
GET/ or /json JSON Random joke payload. Supports ?seed=, ?id=, ?tag=.
GET/html HTML Standalone embeddable 404 page. Supports ?theme=system|dark|light|matrix|glitch.
GET/roast?path=/... JSON / HTML Substitutes missing path with XSS sanitization. Use &format=html for full page.
GET/svg SVG 1200x630 share card for OpenGraph & README embeds.
GET/terminal JSON Array Returns only the terminal logs array for quick CLI integration.
GET/text Plain Text Title, subtitle, and footnote formatted as plain text.
GET/all JSON Array Returns the entire joke library.
GET/stats JSON Most-shown jokes leaderboard with KV sampling.
